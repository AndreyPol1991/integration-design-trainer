# Проектируем интеграцию — интерактивный тренажёр

**Открыть: https://andreypol1991.github.io/integration-design-trainer/**

Тренажёр по проектированию интеграций с нуля: даны три таблицы в базе — нужно получить работающее API.
Ресурсы и адреса, path/query/body, коды ответов, JSON и идемпотентность. Всё интерактивно,
работает целиком в браузере — ничего устанавливать не нужно.

Парный тренажёр к [«Интеграции»](https://andreypol1991.github.io/integrations-trainer/): тот — про то,
**как устроены** HTTP, REST, SOAP и gRPC; этот — про то, **как самому спроектировать** интеграцию
и ответить на вопросы ментора.

## Что закрывает

Тренажёр целиком покрывает чек-лист ментора по блоку «Интеграции»:

| Блок чек-листа | Где в тренажёре |
|---|---|
| Идемпотентность: повторный POST, последствия дублей, Idempotency-Key, второй способ защиты | Раздел 8 — с живым симулятором двойного заказа |
| Проектирование GET-запроса к USER: один, несколько, выбор полей | Раздел 4 — с песочницей «собери запрос — получи ответ» |
| Проектирование эндпоинта APPOINTMENT: метод, endpoint, параметры, ответ, коды, GET vs POST | Раздел 5 — пошаговый конструктор со спецификацией на выходе |
| Поиск ошибок в JSON | Раздел 7 — кликабельная «охота» на 7 ошибок |
| HTTP: 200 / 400 / 404 / 500 | Раздел 6 — игра «дежурный по API» |
| Устная защита: «объясни своими словами» | Раздел 10 — 8 вопросов с эталонами и самопроверкой |

## 12 разделов

| № | Раздел | Ключевой интерактив |
|---|---|---|
| 1 | Задача 📩 | Легенда медцентра, три таблицы, шесть вопросов до первой строчки URL |
| 2 | Таблица → ресурс | Упражнение «фраза заказчика → эндпоинт», шесть правил именования |
| 3 | Path · Query · Body | **Живой конструктор URL**: включаешь кусочки — видишь, как меняется смысл запроса |
| 4 | Кейс USER | **Песочница-сервер**: выбираешь id и поля — получаешь настоящий JSON и разбор формы ответа |
| 5 | Кейс APPOINTMENT | **Пошаговый конструктор эндпоинта** на 10 баллов → готовая спецификация с копированием |
| 6 | Коды ответов | Пять групп, антипаттерн «200 на любую ошибку», игра из 8 ситуаций |
| 7 | JSON 🔍 | **Охота на ошибки**: кликаешь по строке — тренажёр говорит, прав ли ты, и объясняет |
| 8 | Идемпотентность | **Симулятор потерянного ответа**: жмёшь «Оформить заказ» без защиты и с Idempotency-Key |
| 9 | Порядок работы | Восемь шагов проектирования, вопросы бизнесу и смежникам, чек-лист ревью контракта |
| 10 | Скажи словами 🗣 | Восемь вопросов ментора: сначала отвечаешь вслух, потом открываешь эталон |
| 11 | Практика 🎯 | 24 вопроса в 4 кейсах: новая интеграция, ревью чужого API, инцидент в проде, контракт |
| 12 | Капстоун 🏗 | Интеграция с лабораторией: 8 решений → готовая спецификация |

## Механики

- **Направленный маршрут**: кнопки «Дальше →», галочки ✓ на пройденных вкладках, возврат на последнюю вкладку
- **Живой глоссарий**: 40 терминов, в текстах подчёркнуты пунктиром — наведи и увидишь определение
- **Прогресс**: 112 баллов суммарно, сохраняется в браузере (localStorage)
- **Сдача результатов**: в конце генерируется код с результатом — его нужно отправить преподавателю

## Как пользоваться

Просто открыть ссылку выше. Прогресс сохраняется в этом же браузере, так что проходи с одного
устройства. Тема светлая/тёмная — из системы, переключается кнопкой ◐.

Можно и офлайн: скачать `index.html` и открыть двойным кликом.
